📲 ติดตั้งแอปพลิเคชัน

สามารถติดตั้งเป็นแอปพลิเคชันบนมือถือและคอมพิวเตอร์ได้ โดยไม่ต้องต่ออินเทอร์เน็ต

🍎
iPhone / iPad
  1. เปิดในเบราว์เซอร์ Safari
  2. กดปุ่ม "แชร์" (□↑)
  3. เลือก "เพิ่มลงในหน้าจอโฮม"
  4. กด "เพิ่ม"
🤖
Android
  1. เปิดใน Chrome
  2. กดเมนู 3 จุด (⋮)
  3. เลือก "เพิ่มลงหน้าจอหลัก"
  4. กด "เพิ่ม"
💻
คอมพิวเตอร์
  1. เปิดใน Chrome / Edge
  2. กดไอคอน ⊕ ในแถบ URL
  3. หรือกดเมนู → "ติดตั้งแอป"
  4. กด "ติดตั้ง"
💡 การเก็บข้อมูล: ข้อมูลแผน/วิชา/บันทึก → localStorage · ไฟล์แนบ → IndexedDB (รองรับไฟล์ขนาดใหญ่) ข้อมูลจะคงอยู่แม้ปิดแอป
